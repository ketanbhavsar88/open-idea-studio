# Open Idea Studio — web

React + TypeScript + Vite frontend. See [docs/local-development.md](../../docs/local-development.md) to run it and [docs/architecture.md](../../docs/architecture.md) for how it fits together.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to the API on :8080
npm test
npm run lint
npm run build
```
